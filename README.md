# Besy

Видеохостинг: загрузка, хранение, потоковое воспроизведение с перемоткой,
каналы, подписки, лайки и комментарии. Без внешних сервисов — всё работает
на одном Node-процессе и файловой системе.

## Быстрый старт

```bash
npm install
npm start          # http://localhost:3000
```

Требуется **Node.js 22.5+** (используется встроенный модуль `node:sqlite`,
поэтому нативных зависимостей и компиляции нет).

## Что умеет

| Раздел | Возможности |
| --- | --- |
| Аккаунты | Регистрация, вход, сессии в httpOnly-cookie, пароли через `scrypt` |
| Загрузка | Drag-and-drop, прогресс-бар, лимит размера, белый список форматов |
| Обложки | Кадр из видео снимается в браузере (canvas) — ffmpeg на сервере не нужен |
| Просмотр | HTML5-плеер, потоковая отдача с поддержкой HTTP Range (перемотка, докачка) |
| Приватность | Публичное / по ссылке / приватное — с проверкой прав на самом потоке |
| Соцфункции | Лайки и дизлайки, комментарии, подписки, лента подписок |
| Каталог | Лента «Новое» и «Популярное», поиск по названию, описанию, тегам и каналам |
| Статистика | Просмотры с защитой от накрутки (один просмотр на зрителя за 6 часов) |
| Студия | Переименование, смена доступа, удаление, настройки канала |

## Структура

```
server/
  index.js          — сборка Express-приложения, статика, обработка ошибок
  db.js             — схема SQLite и каталоги хранения
  auth.js           — хеширование паролей, сессии, middleware
  routes/
    auth.js         — регистрация, вход, профиль
    videos.js       — загрузка, каталог, реакции, просмотры, комментарии
    channels.js     — каналы, подписки, лента подписок
    media.js        — стриминг (Range), обложки, скачивание
public/             — фронтенд без сборки: HTML + CSS + ванильный JS
scripts/smoke.js    — сквозной тест API
data/               — база и медиафайлы (в git не попадает)
```

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт HTTP-сервера |
| `BESY_DATA_DIR` | `./data` | Куда складывать базу, видео и обложки |
| `BESY_MAX_UPLOAD_MB` | `2048` | Максимальный размер загружаемого файла, МБ |
| `NODE_ENV` | — | `production` включает флаг `Secure` у cookie сессии |

## API

| Метод | Путь | Описание |
| --- | --- | --- |
| `POST` | `/api/auth/register` · `/login` · `/logout` | Аккаунт и сессия |
| `GET` `PATCH` | `/api/auth/me` | Текущий пользователь и настройки канала |
| `GET` | `/api/videos?sort=new\|popular&q=&channel=&limit=&offset=` | Каталог и поиск |
| `POST` | `/api/videos` | Загрузка (multipart: `video`, `thumbnail`) |
| `GET` `PATCH` `DELETE` | `/api/videos/:id` | Карточка, редактирование, удаление |
| `POST` | `/api/videos/:id/view` · `/reaction` | Просмотр, лайк/дизлайк |
| `GET` `POST` | `/api/videos/:id/comments` | Комментарии |
| `GET` | `/api/channels/:username` | Канал |
| `POST` | `/api/channels/:username/subscribe` | Подписка (переключатель) |
| `GET` | `/api/channels/me/feed` | Лента подписок |
| `GET` | `/media/stream/:id` · `/thumb/:id` · `/download/:id` | Медиа |

## Тесты

```bash
npm start &
npm run smoke      # BESY_URL=http://127.0.0.1:3000 по умолчанию
```

Сквозной тест проходит весь путь: регистрация → загрузка → каталог → поиск →
просмотры → реакции → комментарии → Range-запросы (включая `bytes=-50` и 416) →
приватность (чужой не читает приватное видео и не удаляет чужое) → подписки →
вход/выход.

## Развитие

Не входит в текущую версию, но напрашивается дальше: транскодирование в
несколько качеств и HLS через ffmpeg, плейлисты, история просмотров,
уведомления, модерация и вынос файлов в S3-совместимое хранилище.
