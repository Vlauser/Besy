# Besy

Пакетная обработка фото деталей: фон убирается, деталь центрируется на белом
холсте 812×677 и сохраняется в JPEG. Claude API читает маркировку с детали
(`SBHA12-20` → имя файла) и проверяет качество выреза.

## Что делает пайплайн

```
загрузка → rembg (isnet-general-use) → чистка маски → обрезка по контуру
   → масштаб под 69% высоты → центр на белом 812×677 → JPEG q92
   → Claude: OCR маркировки + контроль качества
```

| Проблема исходника | Как решается |
|---|---|
| Серый градиентный фон, тень | Сегментация нейросетью, композит на чистый белый |
| Пыль и блики на фоне | Морфологическое открытие + отсев мелких связных компонент |
| Посторонние объекты в кадре | Отбрасываются вместе с фоном; Claude помечает, если что-то осталось |
| Деталь смещена, кадр не того размера | Кроп по альфа-контуру и центрирование на холсте |
| Непонятно, что за деталь | Claude читает маркировку → она становится именем файла |

**Claude API не редактирует изображение.** Он принимает картинку на вход, но
на выходе даёт только текст, поэтому вырезание и композитинг делает код
(`app/core/processor.py`), а модель отвечает за OCR и приёмку результата
(`app/core/claude_qc.py`). Для технических деталей это принципиально:
генеративная модель «дорисовала» бы геометрию винтов и граней.

## Запуск

```bash
cp .env.example .env      # впишите ANTHROPIC_API_KEY и APP_PASSWORD
docker compose up -d --build
```

Сайт на `http://<сервер>:8000`. Первая сборка тянет модель сегментации
(~180 МБ) внутрь образа, поэтому контейнер стартует сразу и работает
даже без исходящего доступа в интернет (кроме вызовов Claude API).

Локально без Docker:

```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app.main:app --reload
```

### Требования к серверу

2 ГБ RAM на воркера (`WORKERS=2` → ~2 ГБ + сам питон), 2 CPU. GPU не нужен.

## Настройки

Всё в `.env`, полный список с комментариями — в `.env.example`. Главное:

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `ANTHROPIC_API_KEY` | — | Ключ на сервере, в браузер не попадает |
| `APP_PASSWORD` | пусто | **Пустое = сайт открыт всем, кто знает адрес, и все тратят ваш ключ** |
| `ENABLE_CLAUDE` | `true` | `false` — только алгоритмическая обработка, без токенов |
| `CANVAS_WIDTH/HEIGHT` | `812×677` | Размер холста |
| `FILL_HEIGHT` | `0.69` | Доля высоты холста под деталь (снято с референса) |
| `WORKERS` | `2` | Параллельных обработок; каждый держит свою ONNX-сессию |

Те же параметры кадрирования можно менять на самой странице — они применяются
к конкретной пачке, не трогая `.env`.

## Работа с сайтом

Перетащите пачку фото → «Обработать» → галерея заполняется по мере готовности.
Каждая плитка показывает вердикт проверки, найденные проблемы и имя файла
(его можно исправить прямо в поле). Фильтр «Требуют внимания» оставляет только
то, что Claude пометил как `warn`/`fail`, или где сработали локальные проверки.

Кнопка **«С alpha matting»** переобрабатывает один файл с более аккуратным, но
заметно более медленным выделением края — для случаев, когда вырез съел кромку.

**«Скачать ZIP»** собирает готовые файлы под их именами; дубликаты имён
получают суффикс `_2`, `_3`.

Задачи и загруженные файлы хранятся 24 часа, потом удаляются.

## Расход токенов

Одна картинка ≈ 2 тыс. входных токенов (два уменьшённых изображения) плюс
несколько сотен выходных. На `claude-opus-5` это порядка 1–2 центов за фото.
Расход по пачке показывается над галереей. Если маркировка не нужна —
`ENABLE_CLAUDE=false` убирает эту статью расходов полностью.

## API

| Метод | Путь | Назначение |
|---|---|---|
| `POST` | `/api/jobs` | Загрузить пачку (`files[]` + `options` JSON) |
| `GET` | `/api/jobs/{id}` | Статус и результаты |
| `POST` | `/api/jobs/{id}/cancel` | Снять из очереди необработанное |
| `POST` | `/api/jobs/{id}/items/{item}/retry?alpha_matting=true` | Переобработать один файл |
| `PATCH` | `/api/jobs/{id}/items/{item}` | Переименовать результат (`output_name`) |
| `GET` | `/api/jobs/{id}/items/{item}/result` | Готовый JPEG |
| `GET` | `/api/jobs/{id}/download` | ZIP со всеми готовыми |

## Проверено

Пайплайн, очередь, переименование, ZIP, повтор и обработка ошибок протестированы
end-to-end на синтетическом снимке (тёмная деталь, серый градиентный фон, пыль,
тень, посторонняя полоса у края) — фон вычищается, деталь встаёт по центру,
высота выходит ровно 0.69 холста. Установившаяся скорость — 1.3–2.8 с на фото
на 1 CPU без alpha matting.

Успешный ответ Claude API вживую не проверялся: в окружении сборки не было
рабочего ключа. Проверены пути отказа — отсутствующий ключ, неверный ключ,
неразобранный JSON: они не роняют обработку, а попадают в поле `qc.error`
у конкретного файла.
