# Besy

Видеохостинг с адаптивным качеством, прямыми эфирами, модерацией и студией
автора. Работает на одном Node-процессе: без внешних сервисов, без сборки
фронтенда, без нативных зависимостей.

```bash
npm install
npm start          # http://localhost:3000
```

Нужен **Node.js 22.5+** (используется встроенный `node:sqlite`) и, для
адаптивного качества и эфиров, **ffmpeg** в `PATH`. Без ffmpeg сервис
работает — видео просто отдаются в исходном качестве.

Первый зарегистрированный аккаунт получает права модератора.

## Что умеет

### Видео и плеер
- Загрузка drag-and-drop с прогрессом; формат проверяется по сигнатуре файла
- Фоновое транскодирование в лестницу HLS 360p / 480p / 720p / 1080p
- Свой плеер на hls.js: адаптивное качество и ручной выбор, скорость,
  «картинка в картинке», режим театра, горячие клавиши, главы из тайм-кодов
  в описании, продолжение с места остановки, автозапуск следующего
- Субтитры WebVTT и SRT (SRT конвертируется на сервере), выбор языка в плеере
- Отдача с поддержкой HTTP Range: перемотка и докачка на исходном файле
- Доступ: публичное / по ссылке / приватное, отложенная публикация, 18+

### Форматы
- **Shorts** — вертикальные ролики короче минуты попадают в отдельную ленту
  с покадровой прокруткой
- **Эфиры** — приём RTMP, перегон в HLS, чат, ключ трансляции выдаётся и
  меняется из студии
- **Плейлисты** — очередь воспроизведения, порядок, доступ, «Смотреть позже»
- **Сообщество** — текстовые записи канала с лайками

### Защита контента
- Свои видео можно заявить как эталоны: сервер считает отпечатки
- Загрузки сверяются с эталонами по аудиодорожке и видеоряду
- Правообладателю приходит заявка, автору видео — возможность оспорить
- Политика на выбор: пометить заявкой, отслеживать или заблокировать
- Споры разбирает модератор, решение попадает в аудит-лог

### Сообщество и рост
- Лайки, комментарии, подписки, лента подписок и лента «Для вас»
- История просмотров с продолжением, уведомления с колокольчиком
- Студия: аналитика канала и видео (просмотры, время просмотра, удержание,
  источники трафика), массовое редактирование, настройки канала

### Защита
| Механизм | Что делает |
| --- | --- |
| CSP и security-заголовки | На каждом ответе, включая `frame-ancestors 'none'` |
| CSRF | Double-submit токен + проверка `Origin` на изменяющих запросах |
| Ограничение частоты | Отдельные бюджеты для входа, писем, загрузок, комментариев, чата |
| Защита от перебора | Блокировка по паре «логин + IP» с экспоненциальной задержкой |
| 2FA | TOTP (RFC 6238) с QR-кодом и одноразовыми резервными кодами |
| Почтовые сценарии | Подтверждение e-mail и сброс пароля по одноразовым ссылкам |
| Сессии | Список устройств, отзыв одной или всех прочих сессий |
| Загрузки | Контейнер определяется по magic bytes, обложка — только JPEG/PNG |
| Подписанные ссылки | `BESY_SIGNED_MEDIA=on` — HMAC с TTL, привязка к зрителю |
| Антиспам | Дубли, ссылочный флуд, капслок и серии комментариев подряд |
| Модерация | Жалобы, блокировки, 18+, страйки на 90 дней, бан на третьем |
| Авторские права | Заявление в духе DMCA: блокировка и страйк при удовлетворении |
| Журнал | Каждое действие модератора записывается в аудит-лог |

## Что может сам пользователь

Платформа защищает себя и правообладателей — но человеку тоже нужны рычаги.

| Возможность | Что делает |
| --- | --- |
| Блокировка | Заблокированный не комментирует ваши видео, не пишет в чат ваших эфиров и не подписывается. Блокировка односторонняя и незаметная — ему не сообщают. Взаимные подписки снимаются |
| Жалоба на канал | Не только на видео или комментарий: травля обычно размазана по многим записям, и модератору некуда ткнуть |
| Выгрузка данных | `/api/me/export` отдаёт JSON со всем, что сервис хранит: видео, комментарии, подписки, история, сессии. Без доступов — ни хеша пароля, ни ключа 2FA, ни токенов |
| Удаление аккаунта | Требует текущий пароль, чтобы угнанная сессия не могла уничтожить аккаунт. Внешние ключи уносят остальное каскадом |

Модератора заблокировать нельзя — иначе от модерации можно было бы просто
отписаться.

## Структура

```
server/
  index.js          — сборка приложения, статика, обработка ошибок
  db.js             — схема SQLite и миграции
  auth.js           — пароли, сессии, middleware доступа
  security.js       — заголовки, CSRF, лимиты, подписанные ссылки
  totp.js           — двухфакторная аутентификация
  mailer.js         — SMTP или файловый «почтовый ящик»
  transcode.js      — очередь ffmpeg, HLS-лестница, обложки
  live.js           — RTMP-приём и перегон эфира в HLS
  notifications.js  — уведомления и рассылка подписчикам
  storage/          — драйверы хранилища: локальный диск и S3
  fingerprint.js    — отпечатки аудиодорожки и видеоряда
  matching.js       — сверка загрузок с эталонами
  blocks.js         — персональные блокировки и точки их применения
  audit.js          — запись действий модераторов
  routes/           — auth, videos, channels, playlists, moderation,
                      captions, live, analytics, me, posts, matching, media
public/             — фронтенд без сборки: HTML + CSS + ванильный JS
scripts/            — сквозные тесты и утилиты
data/               — база, медиа, письма, сегменты эфиров (вне git)
```

## Переменные окружения

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Порт HTTP-сервера |
| `BESY_DATA_DIR` | `./data` | Куда складывать базу и файлы |
| `BESY_SECRET` | случайный | Ключ подписи медиассылок |
| `BESY_MAX_UPLOAD_MB` | `2048` | Максимальный размер загрузки |
| `BESY_STORAGE` | `local` | `local` или `s3` |
| `BESY_S3_BUCKET` · `_REGION` · `_ENDPOINT` · `_PREFIX` | — | Параметры бакета |
| `BESY_S3_ACCESS_KEY_ID` · `_SECRET_ACCESS_KEY` | — | Ключи доступа |
| `BESY_S3_FORCE_PATH_STYLE` | `false` | Для MinIO и совместимых |
| `BESY_TRANSCODE` | `on` | `off` отключает HLS |
| `BESY_TRANSCODE_CONCURRENCY` | `1` | Параллельных задач ffmpeg |
| `BESY_FFMPEG` · `BESY_FFPROBE` | `ffmpeg` · `ffprobe` | Пути к бинарникам |
| `BESY_SHORT_MAX_SECONDS` | `60` | Граница длительности Shorts |
| `BESY_LIVE` | `off` | `on` включает RTMP-приём |
| `BESY_RTMP_PORT` · `BESY_RTMP_HOST` | `1935` · хост запроса | Приём эфиров |
| `BESY_LIVE_STALE_MS` | `15000` | Через сколько молчания эфир считается завершённым |
| `BESY_SIGNED_MEDIA` · `BESY_SIGNED_TTL` | `off` · `21600` | Подписанные ссылки и их срок |
| `BESY_REQUIRE_EMAIL_VERIFICATION` | `on` | `off` снимает требование подтверждения |
| `BESY_MAIL_TRANSPORT` | `log` | `log` (файлы в `data/outbox`) или `smtp` |
| `BESY_SMTP_HOST` · `_PORT` · `_USER` · `_PASSWORD` · `_SECURE` | — | Параметры SMTP |
| `BESY_MAIL_FROM` · `BESY_PUBLIC_URL` | — | Отправитель и базовый адрес в письмах |
| `BESY_RATE_LIMIT` | `on` | `off` отключает лимиты (только для тестов) |
| `NODE_ENV` | — | `production` включает `Secure` у cookie и HSTS |
| `BESY_RESCAN_RATE_LIMIT` | 10 | Пересканирований на аккаунт в час |
| `BESY_EXPORT_RATE_LIMIT` | 5 | Выгрузок данных на аккаунт в час |

## Эфиры

```bash
BESY_LIVE=on npm start
```

В студии создайте эфир — сервис выдаст адрес RTMP и ключ. В OBS: «Сервис →
Особый», сервер и ключ из студии. Приём слушает порт 1935, сегменты HLS
пишутся на локальный диск (`data/live`), поэтому для эфиров нужен локальный
том даже при хранении видео в S3.

## Модерация

```bash
npm run admin -- <логин>            # выдать права
npm run admin -- <логин> --revoke   # снять
```

Панель — `/moderation`: очередь жалоб, заявления о нарушении авторских
прав, журнал действий.

## Тесты

```bash
npm start &
npm test           # все пять наборов подряд
```

Наборы бьют по запущенному экземпляру (`BESY_URL`, по умолчанию
`http://127.0.0.1:3000`) и читают письма из `data/outbox`:

| Набор | Что проверяет |
| --- | --- |
| `smoke` | Регистрация, загрузка, каталог, поиск, просмотры, реакции, комментарии, Range-запросы, приватность, подписки, HLS-лестница |
| `smoke:security` | Заголовки, CSRF, лимиты, блокировка перебора, 2FA, сброс пароля, сессии, проверка файлов, возрастной доступ, антиспам |
| `smoke:social` | Плейлисты и порядок в них, жалобы, блокировки, страйки, авторские права, баны, аудит-лог |
| `smoke:live` | Субтитры и конвертация SRT, Shorts, реальная RTMP-трансляция через ffmpeg, чат, ротация ключа |
| `smoke:growth` | Аналитика, удержание, источники трафика, уведомления, история, «Смотреть позже», рекомендации, посты, отложенная публикация |
| `smoke:matching` | Эталоны, отпечатки, сверка загрузок, заявки, споры, снятие заявки |
| `smoke:safety` | Блокировки на всех поверхностях, жалобы на канал, выгрузка данных без доступов, удаление аккаунта |

## Что дальше

Не входит в эту версию: перекодирование эфиров в несколько качеств,
автоматические субтитры, монетизация, мобильные приложения и вынос
транскодирования на отдельные воркеры.
