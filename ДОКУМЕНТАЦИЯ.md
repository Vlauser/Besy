# AXIOMANTIC — что можно делать через админку

Админка: `axiomantic.ru/admin/`. Работает без базы данных: всё содержимое
лежит в файле `data/content.json`, перед каждым сохранением создаётся копия.

Правило всей панели: **пустое поле = блок пропадает с сайта.** Рядом с такими
полями стоит подпись «пусто — скроется». Ничего удалять из кода не нужно.

---

## Как понять, что уходит в Яндекс

Откройте **Индексация** — это главный экран для SEO. Там по каждому адресу
сайта видно ровно то, что видит поисковик:

| Что показано | Что это |
|---|---|
| Синяя строка | Заголовок в выдаче — **title**. По нему кликают в Яндексе |
| Серый текст под ней | Описание в выдаче — **description** |
| Зелёный адрес | Как выглядит ссылка в поиске |
| «Заголовок на самой странице (H1)» | То, что читает посетитель. В поиск не идёт |
| Значок «в поиске» / «закрыта» | Индексируется страница или нет, и почему |
| Счётчик 35/60 и 132/160 | Длина. Длиннее — Яндекс обрежет |

Ключевое, что путает чаще всего: **title и H1 — это разные тексты.**
Title живёт в разделе «SEO — страницы», H1 — в разделе самой страницы.
На странице «Индексация» у каждой строки есть кнопка «Изменить», она ведёт
сразу туда, где это поле лежит.

## Разделы админки

### Главная

| Раздел | Что правится |
|---|---|
| Первый экран | Заголовок из трёх частей, текст, две кнопки, картинка, плашки под кнопками |
| Сравнение с обычной разработкой | Две колонки «как обычно» и «как у нас», цифра справа |
| Этапы работы | Шаги с номерами и пояснениями |
| Узнали себя (боли клиента) | Карточки проблем, кнопка под ними |
| Услуги на главной | Карточки услуг: название, цена, срок, состав работ, кнопка |
| Блок с персонажем | Заголовок, текст, кнопка, картинка |
| Проекты на главной | Какие три проекта показывать (по ключам), заголовки блока |
| Вопросы и ответы | Вопросы и ответы. Идут в микроразметку FAQ — Яндекс показывает их прямо в выдаче |
| Блок заявки | Заголовки над формой на главной |

### Страницы

| Раздел | Что правится |
|---|---|
| Портфолио | Проекты: название, ниша, монограмма, описание, задачи, состав работ, стек, скриншот, адрес сайта. Каждый проект получает свою страницу `/projects/ключ` и окно с живым сайтом |
| Услуги | Карточки на странице `/services` |
| Коммерческие страницы | 9 посадочных под запросы: `/landing`, `/landing-price`, `/website-for-lawyers` и другие. У каждой свои H1, title, description, цена, состав, шаги, вопросы, кейсы и перелинковка |
| О студии | Первый экран, иллюстрация, рассказ о студии, принципы, люди в команде с фото |
| Блог | Статьи: заголовок, короткий заголовок для карточки, вступление, «короткий ответ» во врезке, текст, дата, время чтения, автор, куда ведём дальше. Плюс подписи блоков «Ещё по теме» и врезки с предложением |
| Отзывы | Отзывы на главной. Отметка «Заготовка» — отзыв виден с плашкой «Текст для замены», но в микроразметку для Яндекса не попадает |
| Страница контактов | Заголовки, способы связи, вопросы внизу |
| Страница 404 | Надпись, заголовок, пояснение, две кнопки, картинка |

### Настройки

| Раздел | Что правится |
|---|---|
| Контакты, меню, реквизиты | Название, пункты меню (пустой пункт исчезает), телефон, почта, мессенджеры, соцсети, ИНН и ОГРНИП в подвале |
| Поля формы заявки | Названия полей. **Пустое название — поле исчезает с сайта.** Обязательны только контакт и согласие на обработку данных |
| Всплывающая форма | Заголовки в окне «Обсудить проект» |
| Окно «Заявка отправлена» | Что видит человек после отправки |
| SEO — страницы | Title и description для каждой страницы, картинки ссылок, галочки «убрать из поиска» |
| Дизайн | Отступы, ширина, скругления, цвета, размер текста |
| SEO — общие | Основной адрес, robots.txt, коды Вебмастера и Search Console, реквизиты организации для микроразметки |
| Правовые тексты | Политика, согласие, тексты баннера cookie |
| Интеграции | Telegram-бот, почта для заявок, Яндекс.Метрика, свой код в head и перед `</body>` |

### Служебное

| Раздел | Что делает |
|---|---|

## Как укоротить или растянуть сайт

**Дизайн → Размеры и длина страницы.**

| Поле | По умолчанию | Что делает |
|---|---|---|
| Отступы между блоками | 118 px | Главное. 70 вместо 118 укорачивает главную примерно на 1100 px |
| Отступы первого экрана | 120 px | Верх страниц услуг, блога, контактов |
| Ширина содержимого | 1200 px | Шире — строки длиннее, страница короче |
| Скругление углов | 28 px | Ноль — прямые углы |

На телефоне отступы пересчитываются сами. Пустое поле — остаётся как у
дизайнера. Ошибочное значение игнорируется: сломать вёрстку нельзя.

## Что делает сайт сам

- **Адреса.** Одна страница — один адрес. `/services/`, `/Services`,
  `/index.php`, двойные слэши, www и http уводятся 301-м редиректом.
- **Карта сайта.** `/sitemap.xml` собирается сама из страниц, проектов,
  статей и картинок. Закрытые от индексации в неё не попадают.
- **robots.txt.** С директивой `Clean-param` для меток Яндекс.Директа —
  иначе один и тот же адрес с `yclid` считался бы дублем.
- **Микроразметка.** Организация, услуги с ценами, вопросы-ответы, статьи,
  кейсы, хлебные крошки, отзывы. Отзывы-заготовки в разметку не идут.
- **Картинки.** При загрузке пересжимаются в WebP — вес меньше на ~90 %.
  У всех проставлены размеры, чтобы страница не «прыгала» при загрузке.
- **Заявки.** Проверка полей, защита от роботов, ограничение частоты,
  запись в панель, отправка в Telegram и на почту, метки рекламы.
- **Согласия.** Галочка на обработку данных обязательна и убрана быть не
  может — статья 9 152-ФЗ. Согласие на рассылку отдельное — часть 1
  статьи 18 закона о рекламе.

## Мелочи, которые полезно знать

- **Предпросмотр.** В разделе с блоком есть кнопка «Предпросмотр» — видно,
  как правка выглядит на сайте, не выходя из админки. Есть переключатель
  «Компьютер / Телефон».
- **Поиск по настройкам.** Поле сверху в меню: наберите «телефон» или
  «цена» — останутся только нужные разделы.
- **Черновики.** У статьи и проекта есть галочка «Черновик»: не виден на
  сайте и не попадает в карту сайта.
- **Копии.** Перед каждым сохранением создаётся `content.bak.json`.
  Плюс раздел «Резервные копии» — скачать и восстановить вручную.
- **Роли.** Администратор видит всё, редактор — только содержимое,
  без SEO, интеграций и пользователей.
